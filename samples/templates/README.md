# Synthetic data templates

`students_import_template.csv` is the published CSV `v1` template. It is UTF-8
with BOM for common spreadsheet compatibility and its stable header, checksum
and Vietnamese field guide are recorded in `STUDENTS_IMPORT_V1.vi.md`.

The three student records are fictional. Never commit real student CSV files.
See `docs/requirements/STUDENT_IMPORT.md`.
