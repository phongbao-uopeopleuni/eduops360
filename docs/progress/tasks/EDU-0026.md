# EDU-0026 — API authorization guards

The guard loads active, non-revoked, time-valid `UserRole → RolePermission → Permission` rows on every sensitive request. It maps only known resource/action enums, evaluates scope in backend, and denies when no grant matches.

Role delegation requires the actor to possess every permission contained by the target role in a covering scope. The admin API requires explicit `school_id` and `academic_year_id`; global grants are fail-closed until OD-008 is approved. Existing two-step approval tests continue to deny missing submitter and self-approval.
