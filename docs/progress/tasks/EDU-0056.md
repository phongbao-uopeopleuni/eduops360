# EDU-0056 — Clean-checkout foundation CI fix

## Root cause and scope

The first hosted `foundation` check on bootstrap commit `446c0a871854fb8236361801f8a19a7fdd8df5c3` passed backend tests (`93/20`) and OpenAPI, then failed six root test subcases because `tempfile.TemporaryDirectory(dir=ROOT / ".local")` requires its parent to exist. `.local/` is correctly ignored, so a clean GitHub checkout has no parent directory. The `always()` cleanup step then also failed because `infra/.env` had not yet been created.

The bounded fix creates the scratch parent in test setup and guards cleanup on the env-file existence. It does not track `.local`, weaken secret handling, change product behavior or touch database code.
