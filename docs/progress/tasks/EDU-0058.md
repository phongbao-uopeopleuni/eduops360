# EDU-0058 — Kickoff có điều kiện P05-T01

## Phạm vi khóa trước implementation

P05-T01 chỉ tạo model thuần, bất biến cho:

- template thuộc đúng `school_id` và `academic_year_id`;
- ngày trong tuần dùng giá trị ASCII ổn định, không phụ thuộc locale;
- session chỉ biểu diễn `am` hoặc `pm`;
- mỗi slot giữ `start_time` và `end_time` dạng `TIME`, không tự đổi timezone.

(P05-T03), editor/reorder (P05-T02), holiday/make-up/approval/legal source

(P05-T09), frontend và solver Phase 06.
