# EDU-0070 — GitHub Pages UI preview

## Scope and expected behavior

Create a public, static-only preview at `https://phongbao-uopeopleuni.github.io/eduops360/`.
For `VITE_GITHUB_PAGES=true`, Vite emits repository-prefixed assets and the app uses
HashRouter. Without the flag, local/Railway retain `base: '/'` and BrowserRouter.
The preview must clearly disclose that no backend is connected, must not send login
credentials or administrative mutations to GitHub Pages, and must not present a
healthy database, authenticated session, or completed feature as real.

The Pages workflow builds and validates on pull requests but deploys only from
pushes or guarded manual runs on `main` or the explicitly allowed trusted branch
`codex/edu-0070-github-pages`. The Pages artifact contains only `frontend/dist`;
no backend, database, Railway, Docker or real student data.
