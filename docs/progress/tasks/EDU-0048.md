## Saturation behavior

The limiter examines at most `eviction_scan_limit` oldest windows (default 64) while holding its lock. It removes the first expired or not-yet-blocked slot. If none is found within that bounded prefix, it preserves all current entries and does not track the new key. Durable per-account lockout remains the fallback. This task bounds CPU/lock work; it does not claim distributed or durable spraying protection.
