# EDU-0027 — Admin user management

Backend endpoints create pending users, read users and roles, activate/suspend accounts, and grant/revoke explicit scoped roles. Mutations require session-bound CSRF, server authorization and audit/outbox in the same transaction. Self-suspension is denied; suspension revokes active sessions; stale grants stop authorizing immediately.

The `/users` Admin console uses generated OpenAPI types, Vietnamese labels, loading/error/permission states and keyboard-accessible forms. It issues a one-time invitation instead of asking the Admin to choose an initial password. It never treats frontend state as authorization. Browser E2E confirms the CSRF cookie value is sent in the invitation request.
