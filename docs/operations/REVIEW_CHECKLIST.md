# Definition of Done — Review Checklist

- [ ] Requirements / acceptance criteria met, no scope creep
- [ ] Changed paths belong to task and module ownership
- [ ] Frontend type checking / lint / tests applicable and successful
- [ ] Backend unit / integration / migration tests applicable and successful
- [ ] API contract updated and frontend client regenerated if required
- [ ] RBAC, audit, academic-year and time-zone rules reviewed
- [ ] No credentials, real learner data, or sensitive logs in diff
- [ ] Task journal includes old/new behavior, test evidence and open issues
- [ ] Actual Git commit SHA / push remote / PR URL / merge status verified
- [ ] `docs/progress/HANDOFF.md` reflects the current blocker or next task
