# Shared Agent Handoff Protocol

Before editing: read `docs/progress/HANDOFF.md`, `TASK_BOARD.md`, relevant task journal, `git status --short`, branch, and the latest commits. If Git is unavailable, state that explicitly.

During work: record task ID, owner, affected module/files, reason, date+timezone, API/migration impact, tests attempted and open issues. Do not edit another agent's unfinished worktree.

On completion: record exact commands and outcomes, file-level changes, commit SHA **only if verified**, push remote ref **only if verified**, PR URL and merge SHA **only if verified**, blockers, and next steps. Rebuild task board from task journals.

For data import: never log real student names, birthdates, uploaded file contents or tokens. Use batch ID, row numbers and column error codes.
